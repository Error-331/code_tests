# POE

## Cable

- Cat 5e or Cat 6 Ethernet cable (solid or stranded **pure copper**, not copper-clad aluminum);
- Devices should match the same PoE standard (such as 802.3af PoE, 802.3at PoE+, or 802.3bt PoE++) or passive voltage (e.g., 24V vs. 48V);
- Router's PoE output wattage should cover the switch's power draw (plus any devices powered downstream if the switch supports PoE passthrough);
