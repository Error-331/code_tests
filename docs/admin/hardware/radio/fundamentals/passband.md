# Passband (The Signal Carrier)

Passband refers to a range of higher frequencies that can pass through a filter or transmission channel, specifically used to carry modulated signals through the air.

## Key Concepts

- **Frequency Shifting**: it shifts the low-frequency baseband signal to a higher frequency range suitable for wireless transmission;
- **Carrier Dependent**: It requires a high-frequency carrier wave, like 2.4 GHz for Wi-Fi;
- **Filter Driven**: it blocks all frequencies outside its defined upper and lower limits to prevent signal interference;
- **Single Channel**: it typically refers to a single, dedicated frequency lane for one specific transmission;
