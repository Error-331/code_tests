# Broadband (The Data Highway)

Broadband is a high-capacity transmission technique that sends multiple data channels simultaneously over a wide range of frequencies.

## Key Concepts

- **High Bandwidth**: It utilizes a very wide frequency spectrum to maximize data transmission speeds;
- **Multiplexing**: It splits a single cable or wireless band into multiple separate channels so different signals can travel at the same time;
- **Infrastructure Focused**: It describes high-speed internet technologies like fiber-optics, cable, 5G, and DSL;
- **Always-On**: It provides continuous, high-capacity connectivity rather than a point-to-point radio link;
